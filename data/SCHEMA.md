# 브랜드 목록 스키마

`brands.csv` 한 줄이 브랜드 하나. UTF-8, 쉼표 구분, 값에 쉼표가 있으면 큰따옴표로 감싼다.

| 열 | 뜻 | 예 |
|---|---|---|
| id | 영문 소문자·숫자·하이픈. 전체에서 유일 | `hyundai-motor` |
| name_ko | 한국에서 흔히 부르는 이름 | 현대자동차 |
| name_en | 공식 영문 이름 | Hyundai Motor |
| aliases | 다른 부름말, `\|` 로 구분 | 현대차\|HMC |
| country | 출신(본사) 국가 ISO 3166-1 alpha-2 | KR |
| sector | 대분류 (아래 목록에서만) | 자동차·모빌리티 |
| category | 중분류 (아래 목록에서만) | 완성차 |
| brand_type | `corporate`(기업·그룹 이름) / `product`(제품·하위 브랜드) / `both`(기업명이 곧 대표 브랜드) | both |
| parent | 모회사·소속 그룹의 id. 독립이면 비움. 모르면 비움 | `hyundai-motor-group` |
| tier | `mega`(세계적) / `major`(한 나라·업계에서 유명) / `niche`(작지만 알아볼 만한) | mega |
| b2b | 주 고객이 기업이면 1, 소비자면 0 | 0 |
